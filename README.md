# expense-management-backend

Scalable backend service for an expense tracking application using Node.js, Express, and MongoDB with secure authentication and financial analytics APIs.

# 💰 Expense Tracker Backend API

A scalable and secure backend REST API for an Expense Tracker application, built using **Node.js**, **Express**, and **MongoDB**.  
The system allows users to manage income and expenses, set budgets, and generate analytics with proper authentication and authorization.

---

## 📌 Project Overview

This project serves as the backend for a full-stack Expense Tracker system (Web & Mobile).  
It supports secure user authentication, transaction management, budgeting, and financial analytics following industry-standard backend architecture.

---

## 🚀 Features

- User Registration & Login (JWT Authentication)
- Secure Password Hashing (bcrypt)
- Role-Based Access Control (RBAC)
- Expense & Income Management
- Category-wise Transactions
- Monthly Budget Management
- Financial Analytics & Reports
- Soft Delete Support
- RESTful API Design
- Input Validation & Error Handling

---

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Authentication:** JWT (JSON Web Token)
- **Security:** bcrypt, CORS
- **Validation:** Mongoose Validators
- **API Testing:** Postman
- **Deployment Ready:** Render / Railway / AWS
